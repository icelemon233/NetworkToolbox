# 0.2.3 安装器验证

验证环境：Windows 11 x64，2026-10-24。此版本调整安装与卸载向导资源及说明，应用业务实现沿用 0.2.2。

- `pnpm assets`、类型检查、lint、格式检查、21 项自动测试、生产构建、.NET 自包含发布及 native `--self-test` 通过。
- `node scripts/native-smoke.mjs` 的真实只读 Windows 集成检查通过，覆盖网卡、主动 Wi-Fi 扫描、端点、路由器身份、配置预览及网关 Ping；状态保存在隔离运行目录，未应用网络配置。
- `pnpm package` 生成安装版与便携版；NSIS 保留警告即失败的构建规则。成品身份、当前前端与宿主代码、原生版本、9 层 ICO 及安全卸载清单通过 `scripts/verify-package.mjs` 校验。
- 从最终安装包和其内置卸载器分别解出欢迎／完成侧图与页头 BMP，四份文件均与 `pnpm assets` 导出的资源哈希一致；RGB24、尺寸、朝向、行对齐及圆角合成有自动测试。
- 实际打开正式安装包，检查欢迎、安装范围和目录页面后取消。隔离 QA 包使用独立应用 ID、GUID、注册项、快捷方式名称及中文含空格目录，实际检查安装进度和完成页面；取消安装后运行，未启动测试副本。
- 隔离副本静默卸载返回 0，移除所拥有的程序文件和 QA 注册项，保留安装目录内的无关文件和独立测试设置。原有安装的 9 个受保护文件、快捷方式和本地记录哈希，以及 2 个注册项保持一致；原有应用继续运行。

electron-builder 按包名共用的安装器缓存已恢复为现有安装对应的 0.2.2 正式包。后续 QA 构建还需隔离包名或预先备份该缓存。

截图及构建日志保存在忽略提交的 `.runtime/installer-audit-20261024/`。卸载器启动被 Windows 界面自动化工具以 `product policy blocks this app` 拦截，因此没有卸载向导实拍截图；卸载资源校验和静默卸载结果不代表卸载界面已通过人工验收。此次未重新执行修改网络配置、管理员操作或真实设备写入测试。
