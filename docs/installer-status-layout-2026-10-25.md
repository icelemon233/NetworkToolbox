# 安装准备提示排版修复

2026-10-25，适用 FanController 0.4.8、LanDrop 1.2.5、NetworkToolbox 0.2.4 的本地 custom-r4 比较包。

退出确认请求曾把完整警告段落同时写入准备状态，而状态控件固定为 40 DIP，导致末行裁切。现将确认段落留在确认界面，等待期间显示“正在等待应用正常退出”。正常退出、传输中断说明、用户确认及后台事务行为不变。

状态区按实际字体和宽度测量行高，进度条与取消按钮从文字底部排布，并保留版本区间距。受限空间下不显示半行文字，提供完整详情入口。独立后台事务、响应修复、场景缓存与窗口按钮样式保留。

PresentationTests 使用截图中的完整 LanDrop 文案验证：实际文字控件能容纳换行内容，进度条和动作位于文字之后，取消按钮与版本区不相交。协议回归确认完整警告不再进入紧凑状态文本，接受退出仍正常返回。相关规范已写回 Cinna 安装包及 Windows 控件 skill。
