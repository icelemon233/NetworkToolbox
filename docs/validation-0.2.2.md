# 0.2.2 验证记录

本次修改覆盖应用图标、共用控件与主题；基础网络功能的设备验证范围保留在 [0.2.0 记录](validation.md)。环境为 Windows 11 x64、普通用户权限。

- TypeScript、ESLint、Prettier、Vite 生产构建通过；前端 8 项测试通过，其中 5 项覆盖选择框的指针与键盘选择、禁用项、Esc 焦点返回、数字值、原生表单序列化和必填校验。
- 当前版本原生服务的 15 组域测试及路由器协议替身、回环 LAN 传输、合成 pcapng 测试通过。本次没有重新执行代理修改、外网测速、真实路由器写入或管理员捕获。
- Edge/Chromium 真实渲染覆盖深浅主题、各页面可用选择框，以及 1440、1180、1000、900、700 逻辑像素宽度。选择框从触发器下方展开，底部空间不足时翻转，长列表可滚动，长选项换行，窗口没有横向溢出。
- 共用控件样例另测 1、1.25、1.5、2 倍浏览器像素密度的 8 组主题组合，验证必填表单、长文字、菜单边缘、滚动至末项和键盘焦点。它们是合成浏览器密度，不等同于 Windows 原生 DPI 切换；本次没有改变系统缩放或完成多显示器 DPI 实测。
- 表单在宽窗口对齐输入框与操作按钮，窄窗口换行保留正常间距；输入框、按钮和选择框基准高度均为 36 逻辑像素。快捷键提示为 12 px 界面字体，选择框和表单为 14 px。
- 安装包包含当前前端构建、产品身份及图标；主程序、原生服务、安装器、便携启动器和实际卸载器均核对当前 ICO 的 9 个图层。版本化快捷方式 ICO 与源资源逐字节相同。
- 实际每用户升级到 0.2.2，现有 3 条历史记录的文件哈希保持一致。已安装程序的真实窗口检查了主题菜单、进程协议筛选、Esc 关闭和工具页。Windows Shell 返回的桌面快捷方式图像已变为网络分析仪版本。

JSDOM 中的布局几何为测试桩，只用于交互测试；它不作为弹层位置或 DPI 的验收证据。系统高对比度、其他显示器与 DPI、签名和基础功能记录中的未完成设备项均没有计入本次通过。
