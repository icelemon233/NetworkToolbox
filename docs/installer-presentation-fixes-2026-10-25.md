# 安装器绘制修复（2026-10-25）

适用 FanController 0.4.8、LanDrop 1.2.5、NetworkToolbox 0.2.4 的本地 custom-r2 比较包，公共实现仍在 installer/inno/ui。此修订只调整安装界面绘制，应用载荷沿用当前已构建版本。

- 渐变刷默认重复平铺会在透明终点采到下一段不透明色，形成单像素竖线。改为镜像边界采样，不改动场景原图。
- 设置切换改为保留常驻头部、标题与正文，按实际变化批量调整控件。先准备新覆盖层，再统一提交绘制；尺寸、DPI、主题未变时复用场景栅格缓存。路径和快捷方式草稿保留。
- 最小化悬浮使用更清楚的中性灰蓝底色和边框，两种主题分别处理；关闭继续采用危险红色。相邻按钮间切换时只清除对应的旧悬浮状态。

原生 PresentationTests 直接使用实际 GDI+ 绘制与控件实现：明暗主题各覆盖 100/125/150/200% 绘制比例；透明边界相邻像素平均通道跳变从深色基线 111 降至不超过 1；连续开关设置 40 次，常驻控件的显隐事件从基线 160 次降至 0，场景栅格未重绘，草稿和控件句柄保留。另验证首页控件具有实际非零布局范围，以及浅深主题最小化悬浮色确有明显变化。

FanController 的隔离安装器已通过真实鼠标打开设置、保存返回、最小化及恢复检查；恢复后实际观察了最小化悬浮色，确认场景边缘无原来的竖线。上述渲染比例检查不等于在四种物理 Windows DPI 下完成了实机验收。

三款共用同一源码与绘制回归。test-custom.ps1 会运行该绘制测试，再验证交接、新装、升级、取消恢复、卸载和资料保留。生产安装包保持独立比较文件名，不替换既有发布包。
