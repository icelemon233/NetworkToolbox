# Inno 安装器验证

此文保留初版标准向导的验证记录。当前原生场景安装器见 [custom-installer-validation.md](custom-installer-validation.md)。

2026-10-25，Windows 11 x64，普通用户会话。版本为 FanController 0.4.7、LanDrop 1.2.4 和 NetworkToolbox 0.2.3。验证的是新的本地 Inno 包，未替换 GitHub 上的旧版本。

三个应用均通过隔离 QA：首次安装、中文及空格路径、桌面与开始菜单选项、维护互斥、同位置升级、模拟 NSIS 登记迁移、卸载登记清理，以及资料目录和安装目录内用户文件的保留。LanDrop 另外验证了旧“卸载.lnk”的清理。QA 使用自己的注册项、程序目录和快捷方式，未升级日常安装。

FanController 使用模拟主程序和风扇服务验证了正常恢复后退出、拒绝退出、错误目录、静默拦截、隐藏到托盘和旧名称窗口消息。拒绝退出时按实际经过的时间停止等待，不强制结束进程。测试结束后移除临时安装登记。

LanDrop 使用真实打包程序和隔离资料目录验证：运行中的静默安装、卸载会停止；明确传入 `/CLOSEAPP` 后，正常退出并等待进程结束，再执行升级或卸载。资料标记保留。NetworkToolbox 的安装包与当前 Electron ASAR、原生服务、图标及文件哈希核对通过；lint、格式和现有测试也通过。NetworkToolbox 的真实网络任务退出仍需独立的授权实机测试。

真实窗口中已检查安装范围选择、FanController 可编辑中文路径、快捷方式页与空格键切换；检查了 FanController/NetworkToolbox 深色和 LanDrop 浅色欢迎页。截图保存在各项目 `docs`。采用 Inno 的 32 位向导承载 x64 应用，避开 7.1.0 官方记录的 64 位复选框辅助功能缺陷；电脑工具的复选 `Value` 字段仍未反映选中状态，因此没有据此宣称屏幕阅读器验证通过。视觉状态、键盘切换和安装后的选项效果已分别验证。

尚未实测：所有用户模式的实际 UAC 提权、缺少 WebView2 的干净系统、Windows 10、100/125/150/200% 物理 DPI 及跨屏、实际屏幕阅读器、真实风扇硬件恢复和 NetworkToolbox 真实网络任务退出。QA 不安装共享运行库，不操作硬件或网络配置。

产物旁的 `.sha256` 和 `.build.json` 记录安装器哈希、共用脚本哈希及每个载荷文件的哈希；最终交付时已与当前源码及包文件比对。安装包未签名，应用版本未改变，本地比较包使用 `inno` 后缀。正式发布需使用新版本。
