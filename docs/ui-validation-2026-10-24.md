# 2026-10-24 UI 验证

本轮在 `main` 的现有未提交改动上继续修正 UI。开始时已有网络分析仪图标、Radix Select、页面迁移与文档更新；这些内容没有作为本轮新增功能。产品名称、应用 ID、用户数据目录、既有主题键、业务功能和确认素材继续沿用。

## 修改范围

- `src/theme.css`、`src/styles.css`：补齐间距、成功状态和按下状态，统一 36px 控件、14px 正文及 12px 辅助文字；修正 DNS 表单说明造成的底边错位。
- `public/theme-init.js`、`scripts/icon.mjs`、`desktop/product.json`：首屏先读取既有主题；从同一 CSS token 生成原生背景、标题栏颜色和高度。窗口按钮采用 Electron 的 Windows 系统覆盖层，缩放后标题栏跟随其实际可用区域。
- `src/App.tsx`：可保存的 224/56px 侧栏、始终可达的工具搜索、低于 700px 时的导航抽屉、固定在底部的设置入口。抽屉和常规侧栏复用同一导航实现。
- `src/shared/ui.tsx`、`src/shared/dialog.ts`：标签与字段说明分别关联，四组标签页支持方向键、Home、End 和单一 Tab 入口；搜索、导航抽屉、本机与路由器预览共用弹窗焦点逻辑。异步预览在禁用入口前保留焦点，取消后能回到原控件。
- `desktop/main.cjs`、`desktop/preload.cjs`、`desktop/window-preferences.cjs`：区分最小化与进入托盘，设置提供关闭时进入托盘或退出，首次进入托盘显示去向说明；重复启动恢复已有最小化窗口。偏好原子保存，损坏文件保留。新增 IPC 延续主窗口主 frame 校验及固定字段白名单；错误显示保留原生解释。
- 总览区分加载和读取失败，提供重新读取入口；适配器消失时回到实际可用适配器。设置元数据未读到时不再当作系统不支持。成功、失败、停止和无任务状态分别呈现，任务进度使用原生 `progress` 数值语义。

原生窗口 API 测试使用独立的 `.runtime/ui-audit-20261024/native-session/NetworkToolbox`，没有操作现有安装的数据或后台任务。测试启动真实 Electron 窗口和 native worker，覆盖新偏好 IPC、非法字段与其他 renderer 的拒绝、最小化、实际启动第二个实例后的恢复、进入托盘、关闭到托盘、关闭并等待 worker 正常退出。测试完成后隔离进程均退出。

当前显示器为 200% 系统缩放、160Hz；原生窗口另以 1、1.25、1.5、2 倍 renderer zoom 测量最小窗口，工作区和顶部操作没有溢出，标题栏分别约为 40、32、27、20 CSS px，对应系统覆盖层。这里没有作帧率或 160Hz 流畅度结论。

- 没有重新安装、升级或卸载用户现有版本，没有覆盖已发布的安装包。

现有 Cinna 规则足以覆盖本轮修正，未改写共享 skill。供跨项目汇总的验证建议：在弹窗焦点返回条款中补一个明确场景——异步操作会临时禁用原入口时，应在禁用前保留目标，并验证 Esc、取消和提交后的焦点；也要检查自动聚焦是否过早覆盖原入口。
