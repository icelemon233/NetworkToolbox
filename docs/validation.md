# 验证范围

版本：NetworkToolbox 0.2.0。验证环境：Windows 11 x64，系统版本 10.0.26300，普通用户权限。以下记录区分实际设备、回环传输、协议替身和未执行项。

## 自动检查

- TypeScript 严格类型、ESLint、Prettier、依赖 peer 检查和 Vite 生产构建通过；前端 3 项历史比较测试通过。
- 原生 15 组域测试通过，包括 CIDR、扫描与延迟互斥、广播频宽、AP 负载、DNS 压缩与损坏指针、参数拒绝、HTML 编码、凭据脱敏、DPAPI 配置保护、离线厂商及随机地址识别。
- 本地路由器替身通过 SHA256 认证、DPAPI 记住/忘记登录、信道矩阵、完整双频写入、原密码保留、重复/过期计划拒绝和掩码密码保护。这些写入没有接触真实路由器。
- 合成 pcapng 验证以太网/IPv4/UDP 解析与损坏长度拒绝。它不等同于真实 Packet Monitor 捕获。
- Windows TCP 回环验证认证后上传/下载、精确字节数、端口独占、绑定失败后重试和停止后释放。没有使用第二台实体电脑。

## 本机与网络实测

读取了实际网卡、Wi-Fi 广播、链路速率、路由、TCP/UDP 进程端点和 AX3000T 的公开身份。配置预览读取了真实 DNS 与 MTU，但没有应用这些网卡配置。

扩展测试的结果：

| 项目 | 实际结果 |
| --- | --- |
| 原生服务 | 发布版握手与版本正确，普通用户运行 |
| UDP DNS | 当前配置的服务器返回 example.com A 记录 |
| 路由追踪与发现 | 到默认网关的有限跳数追踪，以及仅网关 /32 范围的发现 |
| TCP 与 HTTP | 回环服务的真实端口、HTTP 响应、历史与导出的凭据移除 |
| HTTPS / TLS | example.com 响应与证书读取 |
| 外网测速 | 下载、上传各 1 MiB，实际字节数和速率返回 |
| 公网 IP | 按地址族返回地址或错误；不将 IPv6 查询失败推断为完全不支持 IPv6 |
| Wake-on-LAN | 回环 UDP 接收端核对了完整 102 字节魔术包；没有唤醒实体设备 |
| 当前用户代理 | 仅向绕过列表附加保留的测试域名，回读确认，再恢复加密快照；原配置回读一致 |
| 取消与退出 | 取消 Ping 保存部分样本；退出时等待任务清理，并保存退出时记录 |

测试资料保存在工作目录 `.runtime/`，不进入源码包或程序资源。没有记录或公开用户管理密码。

## Cinna 转换与安装

应用、原生服务、安装器和便携启动器的名称、版本与 Cinna 开发者字段已核对。应用标识和用户数据目录保持不变。ASAR 内的图标与源资源逐字节一致；主程序、原生辅助程序、安装器、便携启动器和实际卸载器均嵌入当前 ICO 的 9 个尺寸图层。

在包含中文和空格的隔离安装目录进行了实际每用户安装：

- 0.1.0 仍在运行时，新安装器返回 20，旧文件哈希不变，没有强杀或替换。
- 0.1.0 正常退出后升级到 0.2.0，名称、发布者、快捷方式和历史记录保持正确。
- 0.2.0 窗口中运行 Ping 时执行同版本重装，应用正常退出，本机进程清空，部分样本保存。
- 重装保留另放入安装目录的测试文件；卸载保留该文件和应用历史，并移除程序与安装记录。

最终输出目录的便携 EXE 从 Windows 系统目录作为工作目录启动成功，使用随包原生服务读取真实数据。在实际 Windows 程序中检查了 Cinna 窗口图标、导航、浅色与深色主题、子网计算、主题跨重开恢复，以及最小宽高附近的窗口布局与滚动。README 截图来自真实程序，使用文档范围地址，不包含真实网络记录。

最小窗口下通过 Ctrl+K 打开搜索、输入工具名并回车进入无线信道页；在交付的便携版中重新完成了真实主动扫描。

触发最小化到托盘后，本机服务继续运行；重复启动便携程序恢复原窗口，仍只有一份本机服务。测试后将主题恢复为“跟随 Windows”。
