## English

Version 1.0.0 resets the three Cinna Windows apps to a common release baseline. It includes the native scene installer, current-user/all-users scope, destination and shortcut settings, an independent background installation transaction, normal cancellation and upgrade recovery. The original application IDs and user-data locations are retained. Distribution keeps only the latest release; future changes increment the semantic application version.

Windows binaries are unsigned. Isolated installation, migration, cancellation recovery and data-preservation checks are automated. Real elevation, additional Windows/DPI environments and physical hardware or network operations retain the documented manual verification limits. Verify downloads against the attached checksums.

## 简体中文

1.0.0 将三款 Cinna Windows 应用统一到新的发布基线，包含原生场景安装器、安装范围、路径与快捷方式设置、独立后台安装事务、正常取消及升级恢复。应用 ID 和用户资料目录保持兼容。分发仅保留最新版，后续修改递增正式语义版本号。

Windows 程序未签名。隔离安装、旧版迁移、取消恢复和资料保留使用自动验证；实际提权、其他系统及 DPI 环境、真实硬件或网络操作仍按验证文档区分。下载后可核对随包校验值。
